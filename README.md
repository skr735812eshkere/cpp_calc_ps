# Домашняя работа №2

## Инструкция по запуску:
### Windows
сборка:
```
cmake -S . -B .build -G Ninja
cmake --build .build
cd .build
```
запуск:
```
./bin/homework2.exe
```

### MacOs
сборка:
```
mkdir build
cd build
cmake ..
make
```
запуск:
```
./bin/homework2.exe
```
---

## Описание проекта

Этот проект реализует систему для инкапсуляции методов класса с произвольной сигнатурой. 
Проект состоит из трех основных компонентов:
1. **Wrapper** — инкапсулирует метод класса, обрабатывает значения по умолчанию
2. **Engine** — регистрирует команды и выполняет их по имени
3. **Subject** — содержит методы с разными сигнатурами для демонстрации
